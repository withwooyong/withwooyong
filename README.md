## 💭 Philosophy

> **"개발의 실행은 이미 AI로 옮겨갔다."**
>
> 남는 일은 무엇을 만들지 정하는 판단과, AI가 안전하게 일할 수 있는 틀을 세우는 것입니다.

> **"좋은 코드는 사람이 읽기 좋은 코드가 아니라, AI가 정확히 읽고 안전하게 고칠 수 있는 구조다."**
>
> 리더의 일은 아키텍처 표준 · 코드리뷰/보안 게이트 · 검증 파이프라인을 세우는 것입니다.

> **"리딩과 실무를 분리하지 않는다."**
>
> 조직을 이끌면서 직접 설계하고 코드를 씁니다.
